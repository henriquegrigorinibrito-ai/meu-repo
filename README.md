# Nachoman LP

Landing page estática do restaurante Nachoman, pronta para publicar em GitHub Pages ou Vercel.

## Estrutura

- `index.html` — página principal
- `uploads/` — imagens e assets
- `support.js` — suporte do runtime

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. No terminal do projeto, rode:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin main
```

3. No GitHub, abra o repositório.
4. Vá em Settings → Pages.
5. Em Source, escolha "Deploy from a branch".
6. Selecione a branch `main` e a pasta `/root`.
7. Salve.

## Link público esperado

O GitHub Pages vai gerar algo assim:

```text
https://SEU_USUARIO.github.io/SEU_REPO/
```
